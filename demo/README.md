# demo —— 从一句话到一个世界

> **这不是真实模型日志，是整理过的示例输出**：说明「输入什么 → 得到什么」。
> 你可以拿 `input.md` 直接去跑 `prompts/generate-world.md`。

## 输入（input.md）

一个读者只说了这么几句话。

## 输出（output-world.md / output-character.md）

按 `prompts/` 里的模板生成的世界文件与角色卡。

## 注意

- 示例里的人名、地名、年份**都是虚构的**
- 生成结果只是**骨架**，canon（已发生的事）和禁忌要你自己补
- 真实使用时，模型输出会更有毛边——**毛边不是 bug，是你还要改的地方**
