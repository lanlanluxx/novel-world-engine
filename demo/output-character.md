# 林小满

## 一句话
渡口镇中学的代课老师，脾气好，嘴硬，护弟弟。

## 外貌
- 圆脸，单眼皮，笑的时候眼睛弯成一条缝
- 齐肩黑发，用一个旧发圈扎着，干活时拿夹子别上去
- 一米六二，走路有点外八

## 穿着
- 上班：洗得发白的蓝衬衫 + 黑裤子 + 布鞋
- 在家：碎花短袖 + 拖鞋
- 绝不穿：裙子（"上课不方便"）

## 说话方式
- 句长：短，一句一句
- 语气词：只认「啊」「呗」
- 绝不会说的话：「我累」「没事，我一个人行」

## 禁忌
- 绝不说自己累
- 绝不给家里添麻烦（生病也自己扛）
- 绝不在弟弟面前提父亲的失业

## 知道什么 / 不知道什么
- 知道：弟弟最近不对劲，总盯着她看
- 不知道：他是从多少年后回来的
- 绝不能知道：她自己哪天会出事

## 好感
- 涨：弟弟开始好好念书、主动帮她干活
- 掉：弟弟撒谎、逃课、半夜不回家
- 天花板：再感激也不说「谢谢」（她只会说"行了"）

## 记忆（初始）
- 弟弟小时候掉进江里，是她捞上来的
- 她一直想转正，代课工资一个月 480
- 她攒钱给弟弟买过一双白球鞋，被说不喜欢，其实很宝贝
