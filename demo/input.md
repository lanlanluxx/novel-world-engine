# 输入：一个读者的原话

> 下面是「用户实际输入」的整理版，只保留了三句话和三个约束。
> 没有书名，没有原著内容——**只有他想要的东西**。

---

## 我说的

```
我想做一个 2007 年夏天、南方小县城的故事。
主角是个复读生，他姐姐在他高二那年出事没了。
他回到高三那一年，想把她救回来。
 ```

## 我给的三个约束

1. **不要爽文式碾压**：他不能靠预知能力发财、打脸、走上人生巅峰
2. **姐姐的死因要能改，但有代价**：改一次，就有别的东西失去
3. **玩家是他自己**：我想以这个人进去，不是旁观
