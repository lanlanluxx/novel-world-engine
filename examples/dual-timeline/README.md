# 示例：双时间线的她（脱敏版）

> 这个示例来自一个真实项目，**人名、校名、地名全部替换过**，不含任何原著内容。
> 用途：演示「双时间线 + 活角色 + 玩家改命」怎么写。

## 文件

- `world.md` —— 世界规则
- `character-linzhixia.md` —— 女主（2005 线）
- `character-shenxu.md` —— 男主（双身同体）
- `route.md` —— 一条路线示例

## 这个世界特殊在哪

**一具意识，两具身体，两条时间线同时存在。**

- 2005：她在南京读大三
- 2026：他在广州上班
- 两人通过聊天窗口认识——**中间隔了二十一年**

## 为什么值得当示例

它同时用到了三种文件里最难写的部分：

1. 世界文件里的「双线」与「代价」
2. 角色卡里的「禁忌」与「好感天花板」
3. 路线里的「意图」与「角色抵抗」
