# 小说世界引擎（Novel World Engine）

> **把任何一本小说，变成能住进去的世界。**
> 角色有自己的日程、会记事、会在聊天窗口里回你；结局不是选项，是你定的。

> 为什么做这个：[docs/why.md](docs/why.md)

## 这是什么

一个**格式 + 提示词 + 运行约定**的开放式仓库。

它不提供任何小说的原文、角色图像或剧情内容——**世界由你自己写进来**。
它提供的是：怎么把一本小说拆成「能跑起来的世界」，以及让里面的角色**像活人一样**的规则。

## 三层结构

```
底层：世界文件     —— 世界观、人物、关系、时间线、禁忌（确定，不可改）
中层：活角色       —— 日程、记忆、说话方式（涌现，不可预测）
上层：玩家改命     —— 你指定路线与结局（导演，可编程）
```

传统游戏只有「底层 + 上层」（写死的剧情 + 选项）；
AI 陪伴只有「中层」（自由但没终点）。
**这套东西三层都在你手里。**

## 三十分钟上手

1. 复制 `schema/world.md`，填成你的世界
2. 复制 `schema/character.md`，写 1–3 个角色
3. 复制 `schema/route.md`，写你想要的那个结局
4. 把三份文件丢给任意支持长上下文的模型，用 `prompts/` 里的模板生成初稿
5. 接一个聊天窗口（本地网页 / Telegram / QQ 机器人），开始玩

## 仓库里有什么

| 目录 | 内容 |
| --- | --- |
| `schema/` | 三种文件的字段定义：世界、角色、路线 |
| `prompts/` | 生成三种文件骨架的提示词模板 |
| `examples/` | 一个脱敏的完整示例 |
| `adapters/` | 接入聊天窗口的说明（不含任何私有运行时） |

## 明确不含（也很重要）

- ❌ 任何小说的正文、设定集、角色立绘
- ❌ 任何 QQ / 微信 协议实现
- ❌ 任何第三方闭源运行时
- ❌ 任何可直接商用的授权内容

**这个仓库只给「格式」和「方法」。**
