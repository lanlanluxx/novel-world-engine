# 世界文件（world.md）

> 世界的“宪法”。**上层可以改路线，AI 可以发挥，但世界文件说了算。**

## 格式

用 Markdown，固定的小节。下面是字段说明，真实填写时每节写 3–10 行即可。

```markdown
# 世界：<名字>

## 时间与地点
- 现在是什么时候：
- 故事发生在哪：
- 时代细节（物价、物件、生活节奏）：

## 规则
- 这个世界成立的前提（重生？穿越？双时间线？）：
- 什么能做到、什么做不到：
- 有没有“信息差”设定：

## 禁忌（角色绝不会做的事）
- 

## 已锁死的事实（canon）
> AI 不许改、不许质疑；改了就整条线重来。
- 

## 留给玩家的岔路
- 哪些事还没发生、可以由玩家决定：
```

## 每条为什么必须写

| 小节 | 作用 | 不写的后果 |
| --- | --- | --- |
| **时间与地点** | 让角色说话有年代感 | 她会在 2005 年用智能手机 |
| **规则** | 决定“超自然”的边界 | 长生不老、随便穿越，故事没有张力 |
| **禁忌** | 角色的底线 | 角色会做自己绝不做的事，人设崩塌 |
| **canon** | 防止 AI 改写已发生的事 | 昨天发生的事今天变了 |
| **岔路** | 给玩家留介入空间 | 玩家只能看，不能改 |

## 一条经验

**「禁忌」比「性格」重要得多。**

写“她骄傲”没用；写“她绝不开口求人”才有用——**这是能被执行、能被违反、能被看见的规则。**

## 双时间线的写法

如果世界是两条时间线（比如 2005 / 2026 同时存在），额外加一节：

```markdown
## 双线
- 线 A：<年份>，<地点>，<谁在这边>
- 线 B：<年份>，<地点>，<谁在这边>
- 连接方式：同一意识？通信？物品？
- 两边能不能互相影响：
- 代价（疲劳？记忆？因果）：
```

**代价一定要写。** 没有代价的设定，玩三天就没意思了。
