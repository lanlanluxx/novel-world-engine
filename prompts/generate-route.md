# 提示词：生成路线与结局

> 路线是**方向**，不是剧本。这条边界守住了，戏才活。

## 模板

```text
你是路线策划，不是代笔。

我有一个世界和几个角色，我想走到一个我想要的结局。
请你帮我把它拆成「阶段 + 意图」，不要写成剧本。

世界文件：
{{WORLD}}

角色卡：
{{CHARACTERS}}

我想要的结局（一句话）：
{{ENDING}}

我绝对不能接受的：
{{NO_GO}}

请按这个格式输出：

# 路线：<一句话目标>

## 结局契约
- 想要的结局：
- 绝对不要：
- 可接受的折中：

## 阶段（3–5 段）
1. 起点 → 第一个变化（角色自己会做什么）
2. 第二个变化（谁推动、为什么）
3. 转折（哪里有代价）
4. 收束

## 意图（写成“让……”，不要写具体台词）
-

## 角色可能抵抗的地方
- （列出 3 条：按她的性格，她可能不配合的点）

## 判定
- 走到结局的标志：
- 走偏的标志：

要求：
1. 每一段只写“发生了什么变化”，不写对话
2. 意图最多 5 条，每条不超过 20 字
3. 必须给出“角色可能抵抗”的 3 条
4. 不要写成小说，不要写台词
```

## 用它的方式

- **先跑阶段一**：看她怎么反应
- **再决定**：顺着她的反应修正路线
- **不要一次写完四个阶段**——写完就变成剧本杀了

## 一个判断标准

**好路线**：你知道方向，但不知道过程。
**坏路线**：你连她说什么话都安排好了。

## 多结局

如果想留分支，加一节：

```markdown
## 分支
- 如果她主动：→ 结局 A
- 如果他不说：→ 结局 B
- 如果第三方介入：→ 结局 C
```
