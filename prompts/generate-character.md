# 提示词：生成角色卡

> 目标不是“描述一个人”，是**写出一套她能照着活的规则**。

## 模板

```text
你是角色卡整理者。请根据下面这个世界文件，写一张「能被执行」的角色卡。

世界文件：
{{WORLD}}

角色要求：
- 角色名：{{NAME}}
- 这个人在故事里的位置：{{ROLE}}
- 我希望她/他给人的感觉：{{FEELING}}

请严格按这个格式输出：

# <名字>

## 一句话
（20 字以内）

## 外貌
- 脸型 / 眼睛 / 头发：
- 身高体型 / 习惯动作：

## 穿着
- 默认：
- 场景切换：
- 绝不穿：

## 说话方式
- 句长：
- 语气词（只允许这几个）：
- 绝不会说的话：

## 禁忌
- （至少 3 条，写成“绝不……”）

## 知道什么 / 不知道什么
- 知道：
- 不知道：
- 绝不能知道：

## 好感
- 涨：
- 掉：
- 天花板（永远不会做的事）：

## 记忆（初始 5 条）
-

要求：
1. 全部写成短句、可判断的规则，禁止形容词堆砌
2. 外貌必须具体到能画出来（颜色、长度、形状）
3. 至少 3 条“禁忌”和 1 条“天花板”
4. 如果信息和世界文件冲突，以世界文件为准
```

## 检查清单（生成完自己过一遍）

- [ ] 有没有一条是“绝不”开头的？
- [ ] “不知道什么”写了吗？
- [ ] 好感是行为，不是数字？
- [ ] 发色、发长、眼型能直接画？
- [ ] 有没有一句话是她绝对不会说的？

**这五项过不了，这张卡就会漂。**

## 进阶：让她“活”起来的三句话

在角色卡末尾加：

```
## 她的一天
- 早上：
- 白天：
- 晚上：

## 独处时
- 她一个人的时候会做什么：

## 被问到时
- 问她在干嘛，她会：
```

这三节能把“角色”变成“生活”。
